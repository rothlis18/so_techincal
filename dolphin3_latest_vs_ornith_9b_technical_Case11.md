1. **Ingestion Rate**: The rate at which data is collected and processed. Typically measured in terabytes per hour (TB/hour).
2. **Filtering Efficiency**: The percentage of data that is successfully filtered according to compliance guidelines. Typically expressed as a ratio (e.g., 80% of data filtered).
3. **Latency**: The delay between data ingestion and filtering. Typically measured in milliseconds (ms).

For example, if a centralized system ingests 100 TB/hour of data and filters 50% of it, the filtering efficiency is 50%. If the latency for this process is 10 ms, then the system can handle 100 TB/hour with a latency of 10 ms.
